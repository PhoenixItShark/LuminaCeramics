# Lumina Ceramics

Лендинг студии керамики ручной работы. React 18 + Vite + Tailwind CSS v4 + framer-motion + lucide-react.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

## Стек

- React 18 (Vite)
- Tailwind CSS v4 (CSS-first config через `@theme`)
- framer-motion
- lucide-react
- Google Fonts: Inter, DM Sans
- Unsplash для изображений

## Структура

```
src/
  main.jsx
  App.jsx
  index.css
  components/
    Navbar.jsx
    Hero.jsx
    Philosophy.jsx
    Collections.jsx
    Process.jsx
    Testimonials.jsx
    Newsletter.jsx
    Footer.jsx
```

## Требования

Node.js 18+ и npm 9+.
